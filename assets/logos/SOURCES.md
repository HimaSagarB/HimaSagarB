# Technology logos

Technology logo SVGs are sourced from [Devicon](https://github.com/devicons/devicon), from each technology's `*-original.svg` file in the `icons` directory. The original colors and paths are retained; a neutral background and padding keep dark marks readable in both GitHub themes.
